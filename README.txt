NetMask
=======
Install:   double-click Install.bat (approve the admin prompt).
Launch:    use the NetMask shortcut on your desktop. It always asks for admin rights.
Uninstall: Settings > Apps > NetMask, or run Uninstall.bat.
Try first: Run-without-installing.bat opens the app straight from this folder.

How it works: NetMask changes the profile name Windows keeps for each saved Wi-Fi
network. It is a local display name on this PC only. The real network name is
untouched. Press Reconnect after renaming so Windows refreshes it.
Original names are saved in C:\ProgramData\NetMask and can be restored any time.
