# NetMask v2.7.1

Fix Windows local-label repair getting stuck when multiple saved Wi-Fi profiles share an SSID.

## Fixes

- Keep the selected network editable when its Windows network GUID, adapter, and saved profile identify it uniquely, even if another profile has the same SSID. Renaming, restoring, and renaming again preserve the network identity.
- Use the same profile selection for the network list and native mutations. Prefer the connected saved profile and exact profile names over SSID matches; stale connection attributes after a rename can resolve through the refreshed label.
- Allow **Save name** with unchanged text when the Windows label and saved profile differ. Require both labels to agree before reporting repair success.
- Check for an occupied label when restoring the original and offer the existing conflict repair action. Keep separate recovery records for both networks; a conflict with its own Windows GUID updates both its label and saved profile and rolls back if the requested rename fails.
- Explain how to recover when Windows cannot identify a unique profile, instead of promising a repair through disabled controls. Ambiguous standalone duplicates remain unavailable for renaming because their identity changes with the profile name.
- Preserve original-name recovery for saved profiles whose historical Windows network row no longer exists, without displaying a false label-mismatch warning.
- Keep older WLAN recovery identities stable after restoration so saved sharing sessions, presets, history, and selection continue referring to the same network. Legacy WLAN mutations also update the matching Windows label when it is uniquely identified. Original values that anchor these identities remain saved after a successful restore.

## Verification and limits

Regression fixtures cover duplicate SSIDs, a partially restored label, stale live profile names, restore followed by another rename, ambiguous identities, conflict recovery IDs, and withholding success while a mismatch remains. Browser checks exercise unchanged-label repair and editing after restoration.

Automated tests use fictional profiles and isolated storage. Windows permissions, reconnects, and adapter behavior require real hardware checks. Local labels do not change the router's broadcast SSID. This patch makes no new performance, publisher-signing, or notarization claim.
