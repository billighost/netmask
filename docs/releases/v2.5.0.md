# NetMask v2.5.0

This release makes local network names more durable on Windows, makes update notifications reliable, and expands sharing privacy without cluttering the main dashboard.

## More reliable local names

- Persist the relationship between a Windows Network List identity and its stable saved WLAN profile before changing either name.
- Recover that relationship after an update when Windows recreates or removes its older Network List row, including cases where the original label does not equal the SSID.
- Audit saved recovery records on the first launch after an update and show a focused repair reminder only when attention is needed.
- Refresh immediately when the native connection watcher sees the active network, adapter, or access point change, while retaining low-frequency fallback refreshes.
- Detect duplicate target labels before requesting administrator permission. **Free this label** safely renames the conflicting saved profile, retries the requested name, and rolls the other profile back if the second change fails.

## Sharing controls that stay out of the way

- Recognize Webex, Slack, Skype, Loom, Riverside, additional Teams and XSplit variants, and NVIDIA Broadcast alongside the existing supported apps.
- Add up to 20 custom executable names in Advanced privacy settings. NetMask matches basenames only and never accepts paths or launches those files.
- Start a persisted 15, 30, or 60 minute private-name session from Settings or the `Ctrl+Alt+S` shortcut. Restoration starts when time expires, including after a long shutdown and restart; the operating system may request permission to restore its label.
- Keep the tray concise while showing the remaining sharing-session time in its existing sharing item.

## Updates, reports, and diagnostics

- Check for updates immediately on startup, retry bounded transient failures, recheck when NetMask becomes visible, and refresh in the background every six hours.
- Prevent late cached update status from hiding a newer result. Settings shows the last check time and any quiet automatic-check error.
- Keep the HTML connection-report preview at the user's scroll position when live speed readings arrive; reports remain point-in-time snapshots.
- Export a private JSON diagnostic containing only versions, capability flags, safe counts, and update/sharing state. It excludes network names, SSIDs, BSSIDs, MAC addresses, hostnames, process names, credentials, and file paths.

## Verification and limits

Automated checks cover updater startup races, stable Windows identity recovery, ambiguous profile refusal, conflict rollback preparation, sharing timers, custom process matching, event-driven refresh, diagnostic redaction, report scrolling, small-window UX, native parsers, subprocess deadlines, and Windows installer compilation. Multi-platform CI separately compiles and tests Windows x64, Apple silicon, Intel macOS, and Linux x64 packages.

The automated suite does not approve a real UAC prompt, rename a live network, reconnect Wi-Fi, notarize a macOS package, or prove every desktop environment's displayed name. Packages do not claim Windows publisher signing or macOS notarization.
