# NetMask v2.3.0

Fieldnotes is here: warm paper, green ink, clearer network names, and the new transparent Orbit logo. This release also finishes the Tauri cleanup and repairs recovery, platform integrations, measurements, updates, and the release pipeline.

## A new interface

- Rebuilt the connection summary, saved network list, name editor, privacy panel, network tools, and every dialog around Fieldnotes.
- Added Paper and Dark themes, custom dropdowns and switches, keyboard menus, and small information popovers that explain technical values in plain language.
- Reworked Settings into General, Privacy, Tools, and About, including a styled Bello Bilal maintainer card.
- Kept content, dialogs, and popovers usable at **320 × 200**. Long names wrap, panels scroll internally, and keyboard focus stays with the active dialog.
- Applied **Orbit, logo 15**, to the app, tray, resources, desktop icon formats, and installer artwork. The selected SVG generates the renderer mark and desktop exports.
- Added Fieldnotes Windows installer artwork and a clearer macOS disk-image screen.

## Repairs and cleanup

- Removed the retired Electron host, preload, packaging, dependencies, scripts, and build configuration. The app uses Tauri 2, Rust, React, and Vite.
- Implemented stable Windows Network List/WLAN, macOS service, and Linux NetworkManager integrations. Unsupported operations and missing measurements explain their limits.
- Moved blocking work off the window thread, bounded subprocesses and network requests, and propagated failed or canceled operations.
- Validated names and preferences, serialized mutations, saved originals before changing a label, and retained unsuccessful restore records.
- Added per-user atomic JSON storage, file locks, safe Windows data migration, and recovery for display-name masking.
- Fixed profile mapping, manual privacy mode, elapsed-time cooldowns, counter resets, real DNS response measurements, and connection-scoped details.
- Corrected Wi-Fi QR credential/security handling. The Share panel explains that credentials are readable and can save the QR image.
- Restricted updates to exact native GitHub assets, verified size and SHA-256, synchronized download status, and rejected arbitrary installer paths.
- Coalesced frontend refreshes, rolled back failed preferences, cleaned up loading state, aligned filtered keyboard selection, and supported Command shortcuts on macOS.
- Rewrote the installation, architecture, contribution, security, performance, release, design, and branding documentation.
- Rebuilt the repository's first impression with the selected Showcase README, real app screenshots, concise feature explanations, and clear downloads. The other three README directions remain available in an offline preview gallery.
- Added Intel Mac builds. Publication now requires six native packages and checksums from all four installer runners.

## Platform and verification notes

Names are local labels; the router keeps broadcasting the same Wi-Fi name. Windows may continue showing that SSID in its Wi-Fi flyout. Display-name and BSSID masking change what is displayed; they do not make the network connection anonymous.

macOS can withhold radio information and require Location Services or Keychain permission. Linux requires NetworkManager and a compatible desktop environment. MAC randomization, NetBIOS, and adapter tuning are currently Windows features where supported by the adapter.

Frontend verification includes 28 behavioral/verification tests and browser checks across 23 scenarios. Native verification includes 27 core tests with isolated storage, sockets, platform data, and subprocess fixtures. These checks do not alter the developer's live network.

Permission prompts, real Wi-Fi reconnects, DNS changes, and driver behavior still need manual validation on the target hardware. Packages do not currently claim verified Windows publisher signing or macOS notarization.
