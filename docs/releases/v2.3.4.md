# NetMask v2.3.4

This release repairs Windows network renaming and makes original-name recovery survive upgrades and uninstall failures.

## Reliable Windows names

- Keep the Windows local network label and its matching saved Wi-Fi profile name synchronized, restoring the behavior users relied on before the Tauri migration.
- Run a user-requested Windows rename in one elevated native helper, and roll back the local label if the saved Wi-Fi profile cannot be updated.
- Wait briefly for Windows and NetworkManager service notifications before treating a protected write as unconfirmed.
- Make the keyboard restore shortcut use the same refreshed snapshot confirmation as the editor and context-menu actions.

## Sharing privacy

- Replace the repeated `tasklist.exe` subprocess with native Windows process enumeration, removing the timeout shown by **Hide names while sharing**.
- Clear a temporary broadcast-app detection error after the next successful scan, so an old failure does not remain stuck in the privacy panel.

## Recovery and uninstall

- Move settings and original-name recovery records out of the Windows installer directory so uninstall cannot delete the only recovery copy.
- Merge recovery records from both the previous per-user install directory and the older ProgramData location. Existing newer records win, and legacy source files remain untouched.
- Restore recoverable network names before both NSIS and MSI uninstall, remove the obsolete elevation task, and retain recovery data when restoration cannot finish.
- Preserve recovery through upgrades; uninstall restoration does not run during an MSI upgrade.

## Verification and limits

Automated tests cover recovery migration, protected-request validation, rename/restore confirmation, native storage, and platform identity mapping. Windows NSIS and MSI builds include uninstall recovery hooks; the compiled MSI was decompiled locally to verify the custom action and uninstall condition.

The automated suite does not approve a real UAC prompt or rename a live network. Windows policies, Wi-Fi drivers, and disconnected historical profiles can still prevent a specific saved profile from being changed; NetMask keeps its recovery record when that happens.

Packages do not claim Windows publisher signing or macOS notarization.
