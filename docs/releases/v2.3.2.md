# NetMask v2.3.2

This release fixes Windows network diagnostics and protected settings, keeps large saved-network collections inside a responsive scroll area, refines search focus, and replaces the former Electron memory claim with a measured Tauri result.

## Windows reliability

- Fix device identity, DNS configuration reads, and Wi-Fi adapter settings on Windows systems that expose adapter GUIDs as strings.
- Run ordinary diagnostics without administrator access. Device identity, DNS comparison, and adapter capability reads now succeed in a standard user session on the tested Windows machine.
- Use the branded NetMask executable as the Windows elevation target for protected changes. The helper accepts only typed, validated NetMask operations; it cannot execute an arbitrary command or write an arbitrary path.
- Use native Windows APIs for protected network-label changes and show clear administrator, cancellation, unsupported-driver, and invalid-parameter errors instead of `powershell.exe failed (exit code Some(1))`.
- Validate DNS, MAC-randomization, NetBIOS, driver, and scheduled-task requests before elevation and verify the resulting operating-system state afterward.

## Interface

- Keep saved networks in a fixed responsive region from 76 to 360 pixels high. The region shrinks with short windows and scrolls internally, including collections with hundreds of networks.
- Show a clean Fieldnotes underline for the saved-network and keyboard-control searches instead of the global red focus outline.

## Measured Tauri memory

On the recorded Windows 11 production build, median private resident memory across NetMask and its isolated WebView2 descendants was **135.8 MiB visible** and **119.6 MiB hidden in the tray**. Each state used 15 one-second samples after a 30- or 60-second settle, with no explicit memory trimming. [Method, ranges, limitations, and raw samples](../../BENCHMARKS.md) are published separately; these values replace the former Electron-era claim and are not a cross-platform guarantee.

## Verification and limits

Automated fixtures do not change a live network. Read-only diagnostics were exercised on a standard Windows user session. The protected helper's parsing and generated commands are covered by native tests, while actual UAC approval and live DNS, driver, NetBIOS, randomization, and display-name mutations remain manual hardware checks.

Memory numbers describe one Windows machine and one measured production build. They are not a cross-platform guarantee. Packages do not claim Windows publisher signing or macOS notarization.
