# NetMask v2.4.0

This feature release makes sharing safer, adds readable connection reports, improves first use and tray access, and gives the Windows setup a clearer finish.

## Sharing mode

- Hide active and saved network names, original labels, searches, editor values, network IDs, device and adapter identity, hardware addresses, detailed notifications, and sensitive dialog fields throughout NetMask.
- Change the supported active network label in the operating system while keeping the original recoverable.
- Protect the renderer immediately while the OS change is still running, and treat a persisted masking record as private from the first startup snapshot.
- Require an explicit exit before loading Wi-Fi QR credentials, changing the private name, exporting recovery names, or restoring original labels.
- Replace the former `tasklist.exe` polling path with native Windows process enumeration.

## Connection reports

- Preview and save a self-contained Fieldnotes HTML report or a Markdown report.
- Include measurements, unavailable states, plain findings, and practical next steps.
- Redact names and hardware identifiers by default; identifier inclusion is an explicit choice and remains unavailable during sharing mode.
- Never include Wi-Fi passwords. Exported HTML escapes untrusted values, and Markdown neutralizes table and inline-HTML injection.

## First use, tray, and installer

- Guide new profiles toward one useful action: name a network, check the connection, or prepare for sharing. Existing profiles are not interrupted.
- Keep the tray focused on Show NetMask, sharing mode, Run connection check, and Quit.
- Open one connection report from the tray, completing first-run state first when necessary.
- Move the Windows setup from successful progress to a clear **Installation complete** page with explicit Finish and Launch wording.

## Reliability

- Block save, restore, backup export, private-name edits, and restore-all paths that could conflict with active sharing.
- Clear search, revealed addresses, and network menus as soon as sharing starts.
- Keep Wi-Fi credentials unloaded and hide detailed DNS, device, adapter, and operation errors while sharing.
- Preserve original-name recovery through uninstall failures and verify Windows name changes against refreshed OS state.

## Verification and limits

Automated checks cover frontend behavior, small-window and dialog UX, sharing redaction, exact report previews and downloads, onboarding, tray events, recovery storage, native platform parsing, process deadlines, and Windows installer compilation. Multi-platform CI separately compiles and tests Windows x64, Apple silicon, Intel macOS, and Linux x64 packages.

The automated suite does not approve a real UAC prompt, rename a live network, reconnect Wi-Fi, notarize a macOS package, or prove every desktop environment's displayed name. Packages do not claim Windows publisher signing or macOS notarization.
