## What shipped

- Tauri v2 desktop host and Rust command modules.
- React bridge for native commands, window controls, and events.
- Native Windows, macOS, and Linux builds in GitHub Actions.
- Synchronized npm/Cargo version metadata and dependency locks.
- A release helper that uses Git Credential Manager without logging credentials.

The native migration has its strongest network-operation support on Windows. Advanced macOS/Linux controls require further platform work. Audit fixes on subsequent branches are separate from this published release.

Renaming a local profile changes an operating-system display name. Your router’s broadcast SSID stays the same. A Wi-Fi QR code contains credentials that a scanner can read.

## Release asset cleanup

Electron compatibility installers, updater manifests, blockmaps, and unpacked build internals have been removed from this release. The five native installers above remain available. Earlier tags have not been changed.

## Validation

The release passed its original local lint, TypeScript, verification, and build checks, followed by GitHub’s Windows, macOS, and Linux checks and installer builds. Version 2.3.0 expands verification with native core, frontend state, and browser interaction tests.
