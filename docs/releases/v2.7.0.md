# NetMask v2.7.0

**Know your connection. Control what you show.**

NetMask is now an always-available, local-first connection companion: review how a connection behaved, prepare what appears on screen, keep local labels recoverable, and turn measured problems into useful evidence.

## Connection journal and observed usage

- Add bounded local history for drops, latency, jitter, network changes, and explicit missing intervals. History is off until enabled, can be paused, supports 7, 30, or 90 days of retention, and can be deleted completely.
- Add observed upload and download totals per saved network with user-defined cycle limits and calm near-limit or over-limit warnings.
- Preserve counter continuity across restarts, resets, adapter changes, network switches, and long gaps by starting a new baseline instead of inventing bytes. Totals describe this computer, not provider billing or other devices.
- Add an evidence-aware weekly digest. It reports insufficient data below its coverage gates and suggests a DNS option only when a user-run comparison measured a meaningful improvement.

## Calls, context, and alerts

- Add **Going live**, which performs fresh gateway, internet, jitter, and sign-in checks, turns on sharing mode, and reports ready, caution, not-ready, or unavailable results in plain language.
- Add opt-in detection for supported call and broadcast apps. Prompt mode asks before acting; automatic sharing mode remains an explicit user choice.
- Add per-network presets for a local label, Fieldnotes theme, and access-point display preference, with a preview, permission explanation, recoverable label application, persisted undo, and safe automatic choices.
- Add opt-in alerts for confirmed access-point or behavior changes. Repeated observations and cooldowns keep them rare, and the copy explains that mesh or managed-network roaming may be normal.

## Provider evidence

- Add previewable HTML and Markdown reports for a chosen period and saved network, built only from retained measurements and explicit gaps.
- Redact identifiers by default, disable label inclusion during sharing mode, state alternative causes and coverage limits, and keep Wi-Fi passwords outside the report schema.

## Tray behavior, privacy, and compatibility

- Keep the existing renderer intact but hidden when NetMask closes to the tray, so reopening returns to the same in-memory state without a normal webview recreation.
- Stop visible-only transfer and sign-in polling in the tray while opted-in history, observed usage, alerts, and context detection continue on reduced native schedules.
- On Windows, request three bounded working-set trim passes for the hidden host and WebView2 processes, cancelling remaining passes as soon as the window returns. This is not a fixed cross-platform memory guarantee; the measured method and results belong in [BENCHMARKS.md](../../BENCHMARKS.md).
- On the documented Windows production comparison, settled tray private resident memory decreased from 122.6 MiB to 30.5 MiB (75.1%). Private commit did not decrease, and no cross-platform RAM or battery-life claim is made.
- Store the journal locally in a versioned, bounded SQLite database. Existing settings and recovery records migrate without losing saved labels, presets, or restoration data.
- Keep Windows, macOS, and Linux capability differences visible in the interface. Unsupported readings and controls remain unavailable with a reason.

## Interface and positioning

- Reposition NetMask around **Know your connection. Control what you show.** while retaining the Fieldnotes interface and Orbit mark.
- Add Journal, Usage, This week, provider-report, preset, alert, and Going live flows with keyboard, screen-reader, Paper/Dark, and 320 × 200 coverage.
- Update the README, architecture, audit, product strategy, security and performance guidance, release process, website, offline studies, installer copy, first-run guidance, and package metadata to match the implemented product boundaries.

## Verification and limits

Monitoring, usage, prompts, and alerts remain off until chosen. Missing samples remain missing. Provider reports use measured local history, redact identifiers by default, and never include Wi-Fi passwords. Sharing mode changes NetMask's display; it does not change the router, hide details in other apps, or provide anonymity.

Automated fixtures do not change a live network. Real counters, permissions, reconnects, installers, and adapter behavior still depend on the target operating system and hardware. Packages do not claim verified Windows publisher signing or macOS notarization.
