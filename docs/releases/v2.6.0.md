# NetMask v2.6.0

This release makes NetMask's quick tour easy to revisit whenever someone wants a refresher.

## A tour you can replay

- Add a clearly labeled **Start quick tour** button to the footer of every Settings tab.
- Close Settings before opening the tour so dialogs never overlap and keyboard focus moves cleanly into the guide.
- Keep the tour action-focused: name a network, check the current connection, prepare for sharing, or continue exploring without triggering any network change merely by opening it.
- Explain inside the guide that it can be replayed later from Settings.

## Verification and limits

Automated browser verification covers the Settings-to-tour handoff, confirms Settings is gone before the guide appears, checks that focus stays inside the guide, exercises the guide's non-destructive exit, and checks responsive dialog geometry. The full frontend and native suites continue to cover settings persistence, network actions, accessibility, update packaging, and release validation.

The automated suite does not approve a real UAC prompt, rename a live network, reconnect Wi-Fi, notarize a macOS package, or prove every desktop environment's displayed name. Packages do not claim Windows publisher signing or macOS notarization.
