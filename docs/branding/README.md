# NetMask branding: Orbit

**Orbit, option 15, is the selected logo for Fieldnotes.** The choice is recorded in [selection.json](selection.json). Its tilted orbit surrounds a connection signal, with a terracotta dot marking one measured moment. The orbit now fits NetMask's broader role as an always-available local connection companion: it suggests observation over time without implying surveillance, anonymity, or router control. It is applied to the app, tray, installers, resources, and desktop icon formats.

Open [the gallery](index.html) in a browser to explore **20 transparent logo directions** for Fieldnotes. It works directly from this folder, without a server or an internet connection.

The first four marks are the original Fold, Signal, Monogram, and Quiet Eye. The next sixteen combine labels, folds, signals, eyes, and letterforms into additional directions. These alternatives remain historical design studies; Orbit is the active identity.

Use the collection buttons to see the originals, new directions, or your shortlist. Add up to four favorites, then choose **Compare favorites** to see their title bars and desktop shortcuts together. Paper and Dark switch the preview colors. Your choices stay in the browser when local storage is available; Orbit stays marked as the current identity while you explore alternatives.

Every option has its own folder under `logos/`:

| File | Use |
| --- | --- |
| `mark.svg` | Editable master in forest green and terracotta; 1024 px canvas |
| `mark-light.svg` | Light ink and a warm accent for dark surfaces |
| `mark-mono.svg` | One-color vector for places that need a single ink |
| `icon.png` | Transparent 512 px PNG for general use |

The gallery's 16, 32, and 48 px previews render the source vector at its displayed size. Dark previews use the light vector, keeping the accent color. The checkerboard belongs to the gallery; it is not part of the artwork.

Regenerate the source variants and desktop exports from [catalog.js](catalog.js):

```sh
node scripts/generate-logo-options.cjs
```

Promote the selected exports and regenerate the renderer mark from the same source SVG:

```sh
node scripts/apply-branding.cjs
python scripts/generate-installer-assets.py
```

The second command requires Pillow; native builds use the committed artwork. It creates the Windows NSIS/MSI bitmaps and macOS disk-image background in `src-tauri/installer/`. WiX's native title area is kept clear.

The renderer's generated [BrandMark.tsx](../../src/renderer/src/icons/BrandMark.tsx), public SVGs, resource files, and Tauri icons share this source. Run the promotion helper after changing the selected master; avoid editing generated variants separately.

For an existing Windows installation whose shortcut has a stale icon, [repair-desktop-shortcut.ps1](../../scripts/repair-desktop-shortcut.ps1) validates the installed executable, backs up the shortcut, copies Orbit's ICO beside the executable, updates the icon location, and refreshes the shell. New installers embed Orbit directly.
