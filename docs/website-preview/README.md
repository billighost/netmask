# NetMask website directions

Open `index.html` directly in a browser. The gallery links to three independent, responsive landing-page prototypes:

1. **The Signal Line** — kinetic editorial railway story.
2. **The Field Atlas** — tactile cartographic field guide.
3. **The Orbit Room** — luminous technical observatory.

**Selected direction: The Field Atlas.** The production implementation uses React and Vite. The unselected pages remain visual references, but their product facts and v2.7.0 links are kept current.

The pages use repository assets and require no build step. They load no remote fonts, analytics, telemetry, or live counters. Download links point directly to the v2.7.0 release assets.
